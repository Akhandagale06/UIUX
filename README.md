**UIUX Web** is an AI-powered web application that turns natural language descriptions into interactive website and mobile application UI/UX designs. Built on Next.js 15, React 19, and Tailwind CSS v4, UIUX Web features an infinite canvas workspace, multi-screen generation, automated code drafting, and real-time live previews powered by Google Gemini via OpenRouter.

---

## ✨ Features

- 🤖 **AI-Powered UI Generation**: Transform text prompts into multi-screen website layouts or mobile app wireframes.
- 🎨 **Infinite Canvas Studio**: Zoom, pan, and arrange generated screen cards inside an interactive infinite workspace powered by `react-zoom-pan-pinch` and `react-rnd`.
- 💻 **Real-Time Code Generation**: Auto-generates fully styled React and Tailwind CSS component code for each screen with live preview rendering.
- 🎭 **Dynamic Theme Engine**: Select from curated color palettes or let AI generate customized theme tokens applied instantly across all project screens.
- 📂 **Screen Management**: Add new screens, customize screen configurations, and update layout purpose on demand.
- 🔒 **User Authentication & Credits**: Integrated with **Clerk Auth** for user session management and credit usage tracking.
- 🗄️ **Serverless Relational Database**: Backed by **Neon PostgreSQL** and **Drizzle ORM** for project metadata, user accounts, and screen configurations.

---

## 🛠️ Tech Stack

### **Frontend & UI**
- **Framework**: [Next.js 15](https://nextjs.org/) (App Router)
- **Library**: [React 19](https://react.dev/) & [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/), Radix UI primitives, Lucide Icons, Magic UI animations
- **Canvas Interaction**: `react-zoom-pan-pinch`, `react-rnd`, `html2canvas`
- **State & Notifications**: React Context, [Sonner](https://sonner.emilkowal.ski/) toast notifications

### **AI & Services**
- **AI Engine**: OpenRouter SDK (`@openrouter/sdk`) leveraging models such as `google/gemini-2.0-flash-001`
- **Authentication**: [Clerk](https://clerk.com/) (`@clerk/nextjs`)

### **Database & Backend**
- **Database**: [Neon Database](https://neon.tech/) (Serverless PostgreSQL)
- **ORM**: [Drizzle ORM](https://orm.drizzle.team/) & `drizzle-kit`
- **API Engine**: Next.js Serverless API Routes (`app/api`)

## ⚙️ Environment Variables

Create a `.env` file in the root directory of the project and add the following keys:

```env
# Database (Neon PostgreSQL)
DATABASE_URL=postgresql://user:password@ep-example-123456.us-east-2.aws.neon.tech/neondb?sslmode=require

# AI API Key (OpenRouter)
OPENROUTER_API_KEY=sk-or-v1-your-openrouter-api-key

# Clerk Authentication
NEXT_PUBLIC_CLERK_PUBLISHABLE_KEY=pk_test_...
CLERK_SECRET_KEY=sk_test_...
NEXT_PUBLIC_CLERK_SIGN_IN_URL=/sign-in
NEXT_PUBLIC_CLERK_SIGN_UP_URL=/sign-up
```

## 🚦 Getting Started

### 1. Prerequisites
- **Node.js**: `v18.x` or higher
- **npm**, **yarn**, **pnpm**, or **bun**

### 2. Installation

Clone the repository and install the dependencies:

```bash
git clone https://github.com/your-username/uiuxweb.git
cd uiuxweb
npm install
```

### 3. Database Push (Drizzle ORM)

Push the database schema to your Neon PostgreSQL instance:

```bash
npx drizzle-kit push
```

### 4. Running the Development Server

Start the local Next.js development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to view the application.
